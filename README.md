# PranaRise - Yoga & Fitness Academy

A luxury single-page website for **PranaRise - Yoga & Fitness Academy**, designed with a **Royal Indigo luxury dark theme** (`#071D32`, `#0B2942`, `#123B5D`, and `#D6A23D` gold accents).

## Features
- **One-Page Architecture**: Seamless single-page application built on Next.js 16 (Turbopack) & React 19.
- **Dynamic JSON-Driven**: All content and assets powered centrally by `components/data/data.json`.
- **Yoga Disciplines & Services**: Hatha Yoga, Vinyasa Flow, Pranayama & Meditation, Ashtanga Power, Restorative Yin, and Yoga Therapy.
- **Curated Membership Packages**: Beginner Yoga, Flexibility & Mobility, Power & Weight Loss, and Stress Relief.
- **Interactive Lightbox Gallery**: High-definition studio yoga asanas and moments with responsive fullscreen preview modal.
- **Online Booking / Appointment**: Interactive consultation and session booking form with direct anchor scrolling.
- **Certified Gurus & Instructors**: Master yoga teachers with personalized biographies and social channels.
- **Responsive & Accessible**: Fully mobile, tablet, and desktop responsive with smooth scrolling and animations.

## Tech Stack
- **Framework**: [Next.js](https://nextjs.org/) 16.4.3 (App Router)
- **UI Library**: React 19, Tailwind CSS v4, Framer Motion, Lucide React, React Icons
- **Image Optimization**: Sharp, Next/Image (WebP)

## Getting Started

### 1. Install dependencies
```bash
npm install
```

### 2. Run the development server
```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

### 3. Build for production
```bash
npm run build
```
